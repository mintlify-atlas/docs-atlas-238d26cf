This page summarizes the major changes in each mcopt release based on available information. For the full diff and release notes, see the [GitHub Releases page](https://github.com/noahdunnagan/mcopt/releases).

<Note>
mcopt is alpha software. APIs, configuration flags, and profile defaults may change between releases without a deprecation period. Back up your worlds before updating.
</Note>

<AccordionGroup>

<Accordion title="0.3.0-alpha.1 — Sodium no longer required">

**mcopt no longer requires Sodium.** Previous versions depended on Sodium for the chunk pipeline and the section-clone cache. From 0.3.0-alpha.1, mcopt is fully standalone — it contains everything it needs with no external renderer dependency.

**Breaking change:** `fabric.mod.json` now declares `"breaks": { "sodium": "*" }`. mcopt will refuse to load alongside Sodium. If you had Sodium in your mods folder for a previous mcopt version, remove it before launching with 0.3.0 or later.

**Own near-terrain renderer.** This release introduces the own Metal terrain renderer, activated by the new `indie` profile (the default). The `indie` profile enables the full set of own-renderer flags — compact vertices, 32-quad compile units, GPU unit occlusion, the own block mesher, translucent sorting, and more — replacing vanilla's Blaze3D terrain path with a native Metal path.

**New default profile: `indie`.** The `indie` profile is the new default when no profile is named. It includes everything from `alpha` (CPU and chunk optimisations) plus the own Metal terrain renderer. The old `alpha` profile remains available as `profile=alpha`. `profile=none` still switches everything off (vanilla renderer).

**Performance (fps spinning / flying, 1920×1080, RD 16, VSync off, same test world):**

| Mac | 0.2.0-alpha.3 | 0.3.0-alpha.1 |
|---|---|---|
| Mac mini M4 (10-core GPU, 16 GB) | 1202–1223 / 1068–1074 | 1209–1211 / 1068–1069 |
| MacBook Neo (A18 Pro, 5-core GPU, 8 GB) | 514–579 / 422–449 | 591–638 / 477–504 |
| Mac mini M6 (12-core GPU, 16 GB) | 1988–1991 / 1738–1742 | 2020–2022 / 1690–1704 |

The mini and Neo cells ran on commit `6c133ecc`, whose only difference from `9865a0a3` is `vGroup`, which is gated off on those GPUs.

</Accordion>

<Accordion title="0.2.0-alpha.3 — Metal renderer">

**First release to draw the world with mcopt's own Metal renderer.** The `alpha` profile delivered vanilla-compatible CPU and chunk optimisations (QoS, fence, texel cache, model reuse, POI loops, chunk ticks, clone cache, light snapshot, edge cap, adaptive frame pacing). 0.2.0-alpha.3 added the Metal rendering path on top, replacing Blaze3D for terrain rendering.

**Performance vs vanilla and Sodium at 1920×1080, RD 16, VSync off:**

| Mac | vanilla | Sodium 0.9.3 | 0.2.0-alpha.3 |
|---|---|---|---|
| Mac mini M4 (10-core GPU, 16 GB) | 156 / 146 | 275–281 / 253–267 | 1202–1223 / 1068–1074 |
| MacBook Neo (A18 Pro, 5-core GPU, 8 GB) | 79–81 / 69–72 | 133–146 / 85–91 | 514–579 / 422–449 |
| Mac mini M6 (12-core GPU, 16 GB) | 297–328 / 283–291 | 454–460 / 406–413 | 1988–1991 / 1738–1742 |

The Neo's vanilla and Sodium cells are from the `da566d00` run, which differs from `9865a0a3` only in code that runs when Distant Horizons is installed.

**Sodium required.** In 0.2.x, mcopt depended on Sodium. This was removed in 0.3.0-alpha.1.

</Accordion>

<Accordion title="Requirements changes over time">

**Current requirements (as of 0.3.0-alpha.1):**

- An Apple Silicon Mac running **macOS 26 or later**
- **Java 25** (the official Minecraft launcher and Prism Launcher download it automatically for Minecraft 26.3)
- **Minecraft 26.3** with **Fabric Loader 0.19.5 or newer**
- **No Sodium** — mcopt breaks alongside Sodium from 0.3.0 onwards

**Fabric API** is not required. Keep it in your mods folder only if another mod needs it. mcopt's own FRAPI integration (`mcopt.own.api`) activates automatically when `fabric-renderer-api-v1` is present.

**Distant Horizons** works alongside mcopt. With DH's default Blaze3D renderer, mcopt draws near terrain on Metal and DH draws its LODs next to it. If DH is configured to its OpenGL renderer (or Iris is loaded), mcopt automatically switches to OpenGL mode (`mcopt.metal=false`) with a startup message. An explicit `mcopt.metal=true` in `config/mcopt.properties` overrides this detection.

</Accordion>

## Planned features

The following improvements are on the roadmap, drawn from the README:

- **Far terrain on by default** with tiers for smaller Macs (currently an experimental opt-in for 10+ GPU core Macs)
- **Our own shaders** (BSL-level) as an option
- **Faster world generation** — native noise, bit-exact
- **More exact server-tick and chunk optimizations**, held for later alphas
- **Faster startup**
- **Wider hardware testing**

<Note>
Far terrain (`mcopt.lod=true`) is available today as an opt-in for Macs with 10 or more GPU cores. See the [far terrain configuration page](/configuration/far-terrain) for setup details.
</Note>
