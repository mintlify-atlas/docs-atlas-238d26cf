mcopt is a performance mod for Minecraft: Java Edition on Apple Silicon Macs. Instead of routing draw calls through OpenGL or MoltenVK, mcopt talks directly to Apple's Metal GPU API — cutting CPU overhead and unlocking the full throughput of M-series silicon. On a Mac mini M4 with a 16-chunk render distance, it reaches over 1,200 fps where vanilla manages 156.

<Warning>
  mcopt is **alpha software**. Expect bugs and back up your worlds before installing.
</Warning>

## Getting started

<Steps>
  <Step title="Install Fabric for Minecraft 26.3">
    Download and run the Fabric installer from [fabricmc.net](https://fabricmc.net/use/installer/), selecting Minecraft 26.3. In Prism Launcher, create a new instance with version 26.3 and loader set to Fabric.
  </Step>
  <Step title="Download the mcopt jar">
    Grab the latest mcopt jar from the [Releases](https://github.com/noahdunnagan/mcopt/releases) page.
  </Step>
  <Step title="Place the jar in your mods folder">
    Copy the jar to `~/Library/Application Support/minecraft/mods`. Create the `mods` folder if it doesn't exist (Finder: Go › Go to Folder). In Prism, open the instance, go to Mods, and click Add file. If Sodium is present, remove it — mcopt won't start alongside it.
  </Step>
  <Step title="Start Minecraft with the Fabric profile">
    Launch the game using the Fabric profile. mcopt activates automatically on Apple Silicon. Press F3 (fn + F3 on a Mac keyboard) to confirm — the bottom right should read `Metal 3 (mcopt)`.
  </Step>
</Steps>

## What mcopt does

mcopt registers a native Metal `GpuBackend` with Minecraft's renderpearl layer. When the game starts on an Apple Silicon Mac running macOS 26+, it draws the world through Metal instead of OpenGL. The default `indie` profile activates mcopt's own near-terrain renderer — compact 40-byte quad records, a GPU unit-occlusion pass, and a custom block mesher that cuts meshing CPU time by 37%. Thread QoS elevation, chunk pipeline speedups (skip duplicate region writes, section-clone cache), and adaptive frame pacing ship with every profile. Far terrain is an experimental opt-in: add `mcopt.lod=true` to your config to render terrain hundreds of chunks beyond the normal render distance using Metal compute shaders and NEON noise generation.

## Requirements

| Requirement | Value |
|---|---|
| Hardware | Apple Silicon Mac (M1 or newer) |
| macOS | 26 or later |
| Java | 25 (downloaded automatically by official launcher and Prism) |
| Minecraft | Java Edition 26.3 |
| Mod loader | Fabric Loader 0.19.5+ |
| Sodium | **Not compatible** — remove it from your mods folder |
