mcopt is a performance mod for Minecraft: Java Edition on Apple Silicon Macs. Instead of routing draw calls through OpenGL or MoltenVK, mcopt talks directly to Apple's Metal GPU API — cutting CPU overhead and unlocking the full throughput of M-series silicon. On a Mac mini M4 with a 16-chunk render distance, it reaches over 1,200 fps where vanilla manages 156.

<Warning>
  mcopt is **alpha software**. Expect bugs and back up your worlds before installing.
</Warning>

## What mcopt does

<Steps>
  <Step title="Replaces the renderer">
    mcopt registers a native Metal `GpuBackend` with Minecraft's renderpearl layer. When the game starts on an Apple Silicon Mac running macOS 26+, it draws the world through Metal instead of OpenGL.
  </Step>
  <Step title="Runs its own terrain pipeline">
    The default `indie` profile activates mcopt's own near-terrain renderer — compact 40-byte quad records, a GPU unit-occlusion pass, and a custom block mesher that cuts meshing CPU time by 37%.
  </Step>
  <Step title="Applies CPU and server optimizations">
    Thread QoS elevation, chunk pipeline speedups (skip duplicate region writes, section-clone cache), and adaptive frame pacing ship with every profile.
  </Step>
  <Step title="Optionally enables far terrain">
    Add `mcopt.lod=true` to your config to render terrain hundreds of chunks beyond the normal render distance using Metal compute shaders and NEON noise generation.
  </Step>
</Steps>

## Requirements

| Requirement | Value |
|---|---|
| Hardware | Apple Silicon Mac (M1 or newer) |
| macOS | 26 or later |
| Java | 25 (downloaded automatically by official launcher and Prism) |
| Minecraft | Java Edition 26.3 |
| Mod loader | Fabric Loader 0.19.5+ |
| Sodium | **Not compatible** — remove it from your mods folder |
